# Digital Invitation Project (toy-50years_mom) 🎂

An interactive and responsive web invitation built from scratch using clean HTML and CSS to celebrate a 50th birthday event.

## Features
- Fully responsive layout optimized for mobile and desktop screens.
- Custom stylized typography and modern UI structure.
- Deployed and hosted live via GitHub Pages.

## Tech Stack
- HTML5
- CSS3
- GitHub Pages (Deployment)
